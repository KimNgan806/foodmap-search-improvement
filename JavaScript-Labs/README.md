## 2. Giới thiệu

Dự án JavaScript Labs tổng hợp các bài thực hành
JavaScript trong học phần Phát triển ứng dụng
Thương mại điện tử.

Mục tiêu là củng cố kiến thức lập trình JavaScript,
thao tác với DOM, xử lý sự kiện và sử dụng jQuery
để xây dựng những chức năng tương tác trên website.

## 3. Nội dung thực hành

### Lab 08 – JavaScript 1: Language Foundations

Trạng thái: Đã thực hành.

Bao gồm Exercise 8.1 đến Exercise 8.11.

Nội dung chính:
- Bật và tắt JavaScript trên trình duyệt.
- Nhúng JavaScript trong HTML và sử dụng file JS ngoài.
- Sử dụng thẻ noscript.
- Kiểm tra và gỡ lỗi bằng Browser Console.
- Làm việc với String, Date và Math.
- Sử dụng mảng và vòng lặp.
- Khai báo hàm và xử lý tham số.
- Làm việc với đối tượng và Constructor Function.
- Duyệt mảng các đối tượng.

### Lab 09 – JavaScript 2: DOM and Events

Trạng thái: Chưa thực hiện.

Nội dung dự kiến:
- Truy xuất và thay đổi phần tử HTML.
- Xử lý các sự kiện người dùng.
- Làm việc với biểu mẫu.
- Kiểm tra dữ liệu đầu vào.

### Lab 10 – JavaScript 3: jQuery

Trạng thái: Chưa thực hiện.

Nội dung dự kiến:
- Sử dụng jQuery Selectors.
- Xử lý Events bằng jQuery.
- Thao tác với DOM.
- Xây dựng hiệu ứng Animation.
- Thực hiện GET Requests.

## 5. Hướng dẫn truy cập

### Truy cập trực tuyến

Trang chủ JavaScript Labs (sau khi triển khai GitHub Pages):

https://kimngan806.github.io/foodmap-search-improvement/JavaScript-Labs/

Từ trang chủ, chọn bài Lab để xem các Exercise.

### Chạy trên máy tính

1. Tải hoặc Clone repository về máy.
2. Mở dự án bằng Visual Studio Code.
3. Cài đặt tiện ích Live Server nếu chưa có.
4. Mở JavaScript-Labs/index.html.
5. Chọn Open with Live Server.
6. Sử dụng các liên kết để truy cập bài thực hành.
