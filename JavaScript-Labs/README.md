đơn giản hóa thao tác với các phần tử HTML, xử lý

### 3. Kiến thức và kỹ năng đạt được

**Sử dụng thư viện jQuery**
- Tích hợp jQuery từ CDN hoặc file cục bộ.
- Sử dụng cú pháp `$(selector)` để lựa chọn phần tử.
- Thao tác với nội dung và thuộc tính HTML.

**Xử lý sự kiện và thao tác DOM**
- Đăng ký sự kiện bằng `.on()`.
- Hủy đăng ký sự kiện bằng `.off()`.
- Thêm và thay đổi phần tử trên trang web.

**Xây dựng hiệu ứng tương tác**
- Sử dụng `.fadeIn()`, `.fadeOut()`.
- Sử dụng `.slideUp()`, `.slideDown()`.
- Tạo chuyển động bằng `.animate()`.
- Xây dựng hiệu ứng xem trước hình ảnh.

**Truy xuất và xử lý dữ liệu AJAX**
- Thực hiện yêu cầu GET.
- Tiếp nhận và hiển thị dữ liệu JSON.
- Xử lý kết quả bằng `.done()`.
- Xử lý lỗi bằng `.fail()`.
- Thực hiện tác vụ kết thúc bằng `.always()`.
